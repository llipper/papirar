Papirar

Política de Privacidade

Última atualização: 4 de junho de 2026

1. Sobre esta política

Esta Política de Privacidade explica como o Papirar trata dados relacionados ao uso do aplicativo e do site. O Papirar é um app de estudo de lei seca com leitura, áudio, marcações, perfil do usuário e acompanhamento básico de atividade de leitura.

Ao usar o Papirar, você declara estar ciente das práticas descritas nesta política.

2. Dados que podemos coletar

O Papirar pode coletar os seguintes dados necessários para funcionamento do app:

  • Dados de conta, como e-mail e identificador do usuário.
  • Dados de perfil, como nome, nome de usuário, foto/avatar e biografia, quando informados pelo usuário.
  • Dados de uso do app, como tempo de leitura, leis acessadas e progresso de estudo.
  • Marcações feitas pelo usuário em trechos de lei seca, como importante, cai muito, revisar ou dominado.
  • Dados técnicos básicos necessários para autenticação, segurança, funcionamento e prevenção de abuso.

3. Como usamos os dados

Os dados são utilizados para:

  • Permitir login e acesso à conta do usuário.
  • Salvar e exibir perfil, avatar e informações de estudo.
  • Registrar marcações e progresso de leitura.
  • Manter a experiência do app sincronizada entre sessões.
  • Melhorar estabilidade, segurança e funcionamento do Papirar.
  • Atender obrigações legais, regulatórias ou solicitações legítimas de autoridades, quando aplicável.

4. Compartilhamento de dados

O Papirar não vende dados pessoais dos usuários. Dados podem ser processados por provedores técnicos usados para operar o aplicativo, como serviços de autenticação, banco de dados, armazenamento de arquivos e hospedagem.

Esses provedores atuam para permitir funcionalidades como login, perfil, avatar, marcações e armazenamento dos dados necessários ao uso do app.

5. Serviços de terceiros

O Papirar pode utilizar serviços de terceiros para autenticação, banco de dados, armazenamento, hospedagem e análise técnica de funcionamento. Esses serviços podem processar dados de acordo com suas próprias políticas de privacidade e termos.

Atualmente, o app usa infraestrutura de autenticação e banco de dados para manter contas, perfis e registros de uso do usuário.

6. Segurança

Empregamos medidas técnicas razoáveis para proteger os dados tratados pelo Papirar. Os dados trafegam por conexões protegidas e o acesso às funcionalidades depende de autenticação do usuário.

Nenhum sistema é absolutamente livre de riscos. Por isso, recomendamos que o usuário mantenha sua senha em segurança e não compartilhe suas credenciais.

7. Retenção e exclusão

Os dados são mantidos enquanto forem necessários para fornecer a conta e os recursos do Papirar. O usuário pode solicitar exclusão ou ajuste de dados entrando em contato pelo e-mail informado nesta política.

8. Direitos do usuário

O usuário pode solicitar, conforme aplicável:

  • Acesso aos dados associados à sua conta.
  • Correção de dados incorretos ou desatualizados.
  • Exclusão de conta e dados relacionados.
  • Informações sobre o tratamento de dados.

9. Crianças e adolescentes

O Papirar é voltado para usuários maiores de 18 anos, especialmente estudantes e pessoas interessadas em estudo jurídico e concursos. O app não é direcionado a crianças.

10. Alterações nesta política

Esta política pode ser atualizada para refletir mudanças no app, em requisitos legais ou em práticas de operação. A data de atualização será indicada no início desta página.

11. Contato

regy@papirar.app
